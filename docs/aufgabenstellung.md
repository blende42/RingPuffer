# Aufgabenstellung

## Ziel

Erstelle ein kleines Java-Konsolenprojekt mit einer einfachen Ringpuffer-Implementierung für Ganzzahlen.

## Anforderungen

- Verwende nur Standard-Java.
- Erzeuge die Quellstruktur `src/ch/allianz/lehrlingsausbildung/ringpuffer`.
- Erzeuge darin die Klasse `Application`.
- `Application` dient als Driver-Klasse und enthält die Methode `main`.
- Erzeuge unter `ringpuffer` ein weiteres Verzeichnis `puffer`.
- Implementiere dort einen Ringpuffer, der genau `6` Ganzzahlen aufnehmen kann.

## Erweiterungsideen

- Füge weitere Testfälle für leeren und vollen Puffer hinzu.
- Erweitere die Konsolenausgabe um Statusinformationen wie Grösse oder Vollständigkeit.
- Implementiere später eine generische Version des Puffers für andere Datentypen.
